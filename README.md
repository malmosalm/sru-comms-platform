# منصة إدارة الاتصال المؤسسي - جامعة سليمان الراجحي

## 1. المقارنة المرجعية (Benchmark)

| المعيار | بوابات الجامعات السعودية (مثال: KAU / KFUPM) | بوابات الخدمات الداخلية (ERP / Service Desk) | المنصة المقترحة |
|---|---|---|---|
| دخول موحد | SSO جامعي | SSO مع الهوية المؤسسية | جاهز كنقطة ربط، ينتظر بيانات مزود الهوية |
| كتالوج الخدمات | قائمة خدمات مصنفة | نماذج طلب مع تصنيف | 8 خدمات (التغطية، التصاميم، التصوير، النشر، الزيارات، الهدايا، المعارض، أخرى) |
| تتبع الطلب | رقم طلب | حالة وتذاكر | GitHub Issues بحالات وعناوين مصنفة |
| آخر المستجدات | قسم أخبار | إشعارات | قسم مستجدات قابل للتحديث |
| أتمتة | بريد إلكتروني | سير عمل آلي | إنشاء البلاغ تلقائياً + نشر تلقائي عبر GitHub Actions |
| العربية RTL | نعم | غالباً | نعم، بهوية SRU (#4F2D83 / #02ADD8 / #9EA9AD) |

ملاحظة: المقارنة مبنية على الممارسة المعتادة في هذا النوع من البوابات، ولم تُتحقق من مواقع المنافسين مباشرة في هذه النسخة.

## 2. أهمية الخدمات (التحقق)

- التغطية والتصاميم والتصوير والنشر: تتكرر يومياً، وتحتاج تتبعاً وتقديراً للحجم.
- الزيارات والهدايا والمعارض: مرتبطة بالبروتوكول، وتحتاج تواريخ وموافقات.
- خانة "أخرى": تلتقط الطلبات غير المتوقعة، ومن خلالها تُكتشف خدمات جديدة.

## 3. التشغيل

1. عدّل `config.js` وضع اسم المستودع (`owner/repo`) وروابط SSO عند توفرها.
2. ارفع المجلد إلى مستودع GitHub على فرع `main`.
3. من إعدادات المستودع: **Settings → Pages → Source: GitHub Actions**.
4. تُنشر المنصة تلقائياً مع كل دفعة (push).
5. كل طلب يُرسل من المنصة يُفتح كـ Issue بعنوان ونوع مصنّفين، ويحمل الوسم `service-request`.

## 4. ما يحتاج تأكيداً قبل الإطلاق

- بيانات مزود الدخول الموحد (SSO) من إدارة تقنية المعلومات.
- اسم المستودع المعتمد وصلاحيات الوصول إليه.
- هل تُسجّل المنصة في خريطة المنصات الرقمية قبل 25 أكتوبر 2026؟
- الرابط النهائي للمنصة بعد النشر.
